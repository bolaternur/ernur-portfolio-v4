# 05 — V5 BUILD PLAN

Strict order. Do not skip stages.

## Stage 1 — Audit
- inspect both GLB files
- inspect keyboard hierarchy
- inspect fonts/assets
- classify existing components as USE / MAYBE / REJECT

## Stage 2 — Research
- collect references by category: hero / nav / transitions / 3D / typography / footer / microinteractions / mobile
- shortlist only patterns that support engineering identity

## Stage 3 — Three visual directions
We create 3 alternatives before full implementation:
1. Precision Industrial
2. Futuristic Engineering Lab
3. Editorial CAD

Only one gets selected.

## Stage 4 — Story / wireframe
Proposed flow:
Hero → identity → Robot 01 → short about → evidence → Robot 02 → experience → next → contact

## Stage 5 — Signature moments
Exactly 3 major memorable interactions.
Everything else remains restrained.

## Stage 6 — 3D production
- preserve Robot 01 choreography
- design unique Robot 02 choreography
- keyboard only if it improves the story
- optimized production GLBs with required node names preserved

## Stage 7 — Microinteraction pass
- hover easing
- button/link feedback
- text reveals
- section entry/exit
- nav state
- loading feedback
- focus states
- touch feedback
- reduced motion

## Stage 8 — Performance + QA
- desktop/tablet/mobile
- Chrome/Safari/Firefox checks
- DPR caps
- offscreen render pause
- Core Web Vitals
- accessibility
- semantic HTML / metadata

## Stage 9 — Final approval
Only after V5 is clearly better than V4 do we merge/replace the current production version.
