# 00 — START HERE

Цель: собрать V5 без хаоса и не повторять ошибку V4.

## Этапы

1. **Assets audit** — оба GLB, клавиатура, шрифты, логотипы.
2. **Research board** — GitHub/Codrops/Awwwards references.
3. **3 visual directions** — выбираем один дизайн до полноценной разработки.
4. **Wireframe** — строим историю сайта.
5. **3D production** — robot #1 + robot #2 + keyboard only if it improves the story.
6. **Motion system** — GSAP/ScrollTrigger/Lenis.
7. **Microinteractions** — hover, focus, text reveal, nav states, loading, transitions.
8. **Performance pass** — gltfpack/Meshopt, mobile DPR, lazy loading, reduced motion.
9. **QA** — responsive, accessibility, browser testing, Core Web Vitals.
10. **Merge to main** only after V5 is visibly better than V4.

## Главное правило

Ни одна библиотека или эффект не попадает в финальный сайт только потому, что выглядит эффектно. Каждый элемент должен усиливать одну из трёх вещей:

- engineering identity;
- robot storytelling;
- usability / perceived quality.
