# 02 — CODROPS COMPONENTS

Это не готовый дизайн сайта. Это библиотека motion-идей, которые можно разобрать и адаптировать.

## Высокий приоритет

1. OneElementScroll — https://github.com/codrops/OneElementScroll
   - reuse one object across scroll states
   - useful for moving a 3D/CAD hero between sections

2. ScrollBasedLayoutAnimations — https://github.com/codrops/ScrollBasedLayoutAnimations
   - Flip + ScrollTrigger composition

3. OnScrollPathAnimations — https://github.com/codrops/OnScrollPathAnimations
   - engineering signal line / path reveal

4. ImageToContent — https://github.com/codrops/ImageToContent
   - project preview → content transition

5. KineticTypePageTransition — https://github.com/codrops/KineticTypePageTransition
   - reference for one memorable page transition

## Средний приоритет

6. OnScrollTypographyAnimations — https://github.com/codrops/OnScrollTypographyAnimations
7. ScrollTextMotion — https://github.com/codrops/ScrollTextMotion
8. ElasticGridScroll — https://github.com/codrops/ElasticGridScroll
9. 3DCarousel — https://github.com/codrops/3DCarousel

## Правило использования

- Не копировать демо целиком.
- Не использовать больше 1–2 сильных эффектов из этой группы одновременно.
- Перед внедрением каждый эффект проверяется на mobile, reduced motion и производительность.
