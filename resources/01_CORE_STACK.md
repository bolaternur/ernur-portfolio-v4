## Как скачивать

Для каждого репозитория:

1. Открой ссылку.
2. Нажми **Code**.
3. Нажми **Download ZIP**.
4. Сохрани в одну папку, например `Downloads/ERNUR_V5_KIT/01_CORE/`.

Не распаковывай всё в проект сайта. Пока это research/toolkit.
