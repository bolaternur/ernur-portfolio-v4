A robot is easier to understand when the interface lets you take it apart.

This case study keeps the real CAD hierarchy visible and turns scroll into a four-part inspection sequence.

Interaction idea

Instead of showing the robot as a static render, I wanted the model itself to explain how it is built.

The sequence starts as an inspection, separates parts outward from the robot’s center, pauses long enough to read the structure, then returns every mesh to its original position.

How it worksHierarchy-aware 3D motion

Preserve the
machine.

Each mesh keeps its original position. During the separation phase, a direction is derived from the robot center and the part moves outward while the original assembly state remains recoverable.

That means the animation is not a destructive edit and the rebuild phase can return the actual model to its initial structure.

The goal isn’t to make a robot spin. It’s to make its structure understandable.
